## 查看和继续维护

本机预览：`http://127.0.0.1:4173/en/` 或 `http://127.0.0.1:4173/zh-CN/`。

如果预览服务已关闭，在项目目录运行：

```powershell
pnpm run start -- --host 127.0.0.1
```

图片源文件位于 `design-assets`，网页素材位于 `client/public/images`。以后替换图片请维护 `client/src/content/media.ts`，并运行上述根路径与子路径验证。

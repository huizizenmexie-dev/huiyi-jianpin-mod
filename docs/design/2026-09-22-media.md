## Editing and maintenance

Use the source photos for future artwork and the WebP versions for web pages. Do not point pages back at the former builder's CloudFront image URLs. To replace an image, retain its manifest filename or update the shared media map, and run the image tests plus root/subpath static validation. Product image frames use `object-fit: contain` to protect portrait labels and complete sample arrangements.
